## 兩次問題
1. **Python 3.14 致命錯誤**：本機測試伺服器在 Playwright 直接關閉頁面時當掉
   （`Fatal Python error: _PySemaphore_Wakeup: parking_lot: ReleaseSemaphore failed`，uvicorn websocket 執行緒）。
   屬 Python／Streamlit 執行環境問題；測試改成先導向 about:blank 再關閉後未再發生。使用者正常使用不太會觸發，
   若桌面版出現「伺服器突然結束」可考慮改用 Python 3.13。
2. **雲端示範帳號仍約 27 秒**：先前量到「平面圖 183 秒」是測速程式判斷條件錯誤（實際 2 秒）。
   真正瓶頸是「按示範帳號 → 首頁」。單一交易＋背景預先計算在本機有效，但雲端在登入畫面先等 40 秒再按仍 27 秒，
   表示背景預先計算在雲端沒有生效或瓶頸不在計算。
   下一步建議：
   - 在「說明」頁加診斷區塊（伺服器 CPU 數、worker_count、背景預先計算是否完成與耗時、各步驟耗時），從瀏覽器讀取
   - 檢查雲端的 sim_key 是否與預先計算一致（雲端示範帳號的設定 JSON 經 PostgreSQL 存取後順序或型別可能不同）
   - 檢查 Supabase 連線（pool_pre_ping、每次 rerun 的 autosave 與 load_profile 往返次數）
   - 考慮把預設結果預先算好存成檔案隨程式部署（冷啟動直接讀取）
